# Oasis Infobyte Data Analytics Internship

This repository contains the projects I completed as part of my Oasis Infobyte Data Analytics Internship. The projects helped me practise data cleaning, exploratory data analysis, data visualization, and basic machine learning using Python.

## Projects

### Level 1 — Task 1: Retail Sales Exploratory Data Analysis
**Folder:** [Task-1](Task-1/)

- Explored retail sales data using Python and Pandas.
- Analysed sales, product categories, customer demographics, and transaction amounts.
- Used visualizations to identify patterns and trends.

### Level 1 — Task 3: Data Cleaning
**Folder:** [Task-3](Task-3/)

- Inspected the dataset for missing values and duplicate records.
- Cleaned and prepared the data for further analysis.
- Saved the cleaned dataset for reuse.

### Level 2 — Task 1: House Price Prediction
**Folder:** [Level-2-Task-1](Level-2-Task-1/)

- Used the California Housing dataset from Scikit-learn.
- Trained a Linear Regression model to predict house values.
- Evaluated the model using MAE, RMSE, and R² score.
- Visualized actual versus predicted values and prediction errors.

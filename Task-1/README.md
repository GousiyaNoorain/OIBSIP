# Task 1: Retail Sales Exploratory Data Analysis

## Objective
Analyze retail sales data to identify sales trends, customer demographics, and product-category performance.

## Tools
Python, Pandas, Matplotlib, Seaborn, Google Colab.

## Analysis
- Dataset inspection and descriptive statistics
- Monthly and quarterly sales trends
- Customer age-group and gender analysis
- Product-category revenue and transaction analysis
- Correlation heatmap
- Average transaction amount by age group
- Business recommendations

## Dataset Source
https://www.kaggle.com/datasets/mohammadtalib786/retail-sales-dataset

## Limitation
The dataset does not include individual product names, so the top 10 individual best-selling products could not be identified.
